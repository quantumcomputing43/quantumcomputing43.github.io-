# QUANTUM33 — Clean Research Repository V1

A clean rebuild of the QUANTUM33 research website and its public computational artifacts.

## Website

Open `index.html` for the homepage.

- `miRNA21.html` — miRNA-21 quantum sensing
- `axion.html` — AI Quantum Agent / Axion V15
- `archive.html` — research archive

## Research artifacts

The site exposes the current miRNA-21 identifiability artifacts and the reconstructed Axion V15 baseline under `assets/projects/`.

## Local preview

Any static HTTP server can be used, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.
