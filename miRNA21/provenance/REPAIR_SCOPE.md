# Repair Scope

This branch is intentionally conservative.

### Allowed

- namespace and directory organization
- provenance/status documentation
- explicit blocker documentation
- preservation of historical-versus-current boundaries
- deterministic repository metadata

### Forbidden without recovered authoritative evidence

- inventing R8D transform coefficients
- inventing feature order or dimensions
- recreating V5 source from remembered numerical checkpoints
- changing V1 thresholds or metrics after results
- adding biological features such as NUP153 to R8D
- substituting WHEL endpoints
- converting infrastructure success into scientific PASS
