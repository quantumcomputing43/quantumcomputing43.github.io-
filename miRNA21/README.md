# miRNA-21 — Representation Information Retention

This directory is the project namespace for the miRNA-21 representation-information-retention work.

## Scientific boundary

The project evaluates whether a molecular representation can retain predefined biological-state information. A computational retention result is not biological validation, minimality proof, mechanism, causality, or quantum advantage.

## Current representation state

- R0_full: full RNA benchmark
- PCA25: unsupervised compressed benchmark
- R3_miR21_only: miR-21-only representation
- R8D_frozen: frozen multi-task PLS 8D candidate
- R8D_null: null-control concept requiring exact executable/provenance binding before V1 execution

R8D remains a promising computational/task-preserving representation, not a proven biologically minimal representation.
